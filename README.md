# E-commerce Full Stack

Aquest projecte és una aplicació d’E-commerce de plantes Full Stack desenvolupada a clase.

## Tecnologies utilitzades

- React (frontend)
- Node.js + Express (backend)
- MongoDB (base de dades)
- Docker (contenidors)
- GitHub (control de versions)
- VSCode (entorn de desenvolupament)

## Requisits previs

- Node.js i npm instal·lats
- Git instal·lat i configurat
- Compte de GitHub
- VSCode amb extensions recomanades (ESLint, Prettier, GitLens, Docker, MongoDB)
- Opcional: Docker instal·lat
