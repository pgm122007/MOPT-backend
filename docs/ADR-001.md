# ADR-001: Elección de la base de datos

## Contexto

La aplicación será un e-commerce de venta de plantas.
Necesitamos almacenar usuarios, plantas, direcciones y pedidos.
Además, en el futuro podrían añadirse nuevos atributos a las plantas,
como necesidades de riego, temperatura recomendada o nivel de dificultad.

## Decisión

Se utilizará MongoDB como base de datos principal del proyecto,
gestionada mediante Docker durante el desarrollo.

## Consecuencias

### Positivas

+ Flexibilidad para añadir nuevos campos sin modificar esquemas rígidos.
+ Buena integración con Node.js.
+ Fácil despliegue mediante contenedores Docker.
+ Adecuada para almacenar documentos de pedidos con sus productos.

### Negativas

- Menor eficiencia en consultas muy relacionales.
- Es necesario diseñar correctamente los documentos para evitar duplicidad de datos.
