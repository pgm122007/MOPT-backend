# ADR-002: Estructura inicial del proyecto

## Contexto

La aplicación estará formada por un frontend desarrollado con React
y un backend desarrollado con Node.js.

Es necesario organizar el código de manera clara para facilitar el
desarrollo y el mantenimiento.

## Decisión

Se separará el proyecto en dos aplicaciones independientes:

- Frontend (React)
- Backend (Node.js)

Cada parte tendrá sus propias dependencias y configuración.

## Consecuencias

### Positivas

+ Mejor organización del código.
+ Desarrollo independiente del frontend y backend.
+ Facilita el despliegue y mantenimiento.
+ Permite trabajar en diferentes módulos simultáneamente.

### Negativas

- Requiere gestionar dos proyectos.
- Es necesario configurar la comunicación entre frontend y backend.
